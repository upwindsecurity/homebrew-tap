# homebrew-tap

Homebrew tap for [Upwind Security](https://upwind.io) command-line tools.

## Installation

Add the tap and install `upwindctl`:

```sh
brew tap upwindsecurity/tap
brew install upwindctl
```

Or in a single command, without tapping first:

```sh
brew install upwindsecurity/tap/upwindctl
```

## Upgrading

```sh
brew update
brew upgrade upwindctl
```

## Uninstalling

```sh
brew uninstall upwindctl
brew untap upwindsecurity/tap
```

## Formulae

| Formula | Description |
| --- | --- |
| [`upwindctl`](Formula/upwindctl.rb) | Command-line interface for Upwind Security services |

Formula files are generated by the release workflow in `upwindsecurity/upwindctl` — do not edit them by hand.
